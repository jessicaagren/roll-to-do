# Roll To Do

This is a To Do where you fight a dragon by finishing tasks.

## Features

- Add tasks to your own to do list
- Roll a D20 to choose task
- Check the tasks off your list and gain points to kill the dragon

## Download and run project

To download the project, run `git clone` + `url` in the terminal.

Go to the project root folder and run `npm i` to install necessary packages.

Then run `npm run dev` to compile and run the project.

## Technologies

The techstack is React, Typescript and Tailwind, built with the help of Vite.
